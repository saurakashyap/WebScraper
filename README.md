# AI Web Scraper

An AI-powered web scraping application that extracts website content and uses a Large Language Model (LLM) to generate intelligent summaries and insights.

## Features

- Web content extraction using Selenium
- HTML parsing with BeautifulSoup
- AI-powered content analysis using Ollama and Llama 3.2
- Interactive Streamlit interface
- User-defined prompts for customized analysis
- Automated data extraction and processing

## Tech Stack

- Python
- Streamlit
- Selenium
- BeautifulSoup
- LangChain
- Ollama
- Llama 3.2

## How It Works

1. Enter a website URL
2. Scrape and extract website content
3. Process and clean the extracted data
4. Submit a custom prompt
5. Generate AI-powered insights using a local LLM
